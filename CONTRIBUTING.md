# Contributing to ComfyUI-SeedVR2_VideoUpscaler

This repository stays online as a reference for existing workflows. It no longer accepts contributions. Pull requests and issues are no longer reviewed.

ComfyUI has supported SeedVR2 natively since [v0.28.0](https://github.com/Comfy-Org/ComfyUI/releases/tag/v0.28.0) (July 2026), so this custom node is no longer maintained. The [official guide](https://docs.comfy.org/tutorials/utility/seedvr2) covers the native templates, the models and troubleshooting.

Thank you to everyone who contributed. Many of you are named in the README's [Credits](README.md#-credits).
